# 나스 팝업스토어 — 가까이서 봐도 매끄러운 p1 실내 LED를 시공했습니다

## 롯데백화점 본점 지하 1층에 들어선 나스 팝업스토어

서울 소공동 롯데백화점 본점 지하 1층 원형 공간에 마련된 **나스(NARS) 팝업스토어**에 **p1 픽셀 피치의 실내 LED 전광판을 시공**했습니다. 팝업 안쪽 정면에서 인물 화보와 립 제품 영상이 재생되는 메인 화면입니다.

백화점 팝업의 화면은 멀리서 보는 간판이 아니라 **관람객이 바로 앞까지 다가와 사진을 찍는 화면**입니다. 그래서 이번 시공은 근접 관람을 기준으로 제품과 점검 순서를 잡았습니다.

## 1. 가까이서 보는 화면이라 p1 피치를 적용했습니다

관람객이 화면 앞까지 다가오는 현장이라 **픽셀 간격이 촘촘한 p1 실내용 LED**를 적용했습니다.

- 픽셀 간격이 촘촘해 **가까운 거리에서도 화면의 격자가 덜 보입니다**
- 스마트폰으로 촬영할 때 생기기 쉬운 **모아레를 줄이는 데 유리한 조건**입니다
- 인물 화보와 립 제품이 크게 나오는 영상에서 **피부톤과 제품 색감**이 또렷하게 보입니다

## 2. 붉은 카펫과 어두운 마감 사이에서 화면 색을 확인했습니다

팝업 바닥은 붉은 카펫이고 주변 마감은 어두운 톤입니다. 이런 공간에서는 화면 색이 주변에 묻히거나 반대로 튀어 보일 수 있습니다. 그래서 설치 후 **현장 조명 아래에서 실제 콘텐츠를 띄워 밝기와 색감을 확인**했습니다.

## 3. 점등부터 콘텐츠 송출까지 단계별로 점검했습니다

- 전원을 넣어 **화면 전체 점등 상태** 확인
- 브랜드 로고 화면으로 **표시 이상 여부** 확인
- 실제 **캠페인 콘텐츠를 송출**해 색과 밝기 확인

팝업은 오픈 일정이 정해져 있어, 오픈 후에 문제를 발견하면 되돌리기 어렵습니다. 그래서 시공 단계에서 미리 확인하는 방식으로 진행했습니다.

## 4. 다른 공정과 함께 움직이는 백화점 시공 현장

백화점 팝업은 인테리어 마감, 조명, 집기 작업이 **한 공간에서 함께 진행**됩니다. 화면 시공과 점검도 이런 현장 여건에 맞춰 진행했습니다.

솔미디어랩은 LED 설치, 렌탈, 유지보수까지 직접 진행합니다. 백화점·쇼핑몰 팝업스토어나 브랜드 쇼룸에 LED가 필요하시다면 계획 단계부터 상담해 주세요.
