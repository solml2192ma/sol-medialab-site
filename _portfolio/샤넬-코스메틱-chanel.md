# 성수동 샤넬 코스메틱 팝업 — 모서리를 돌아가는 P2 LED 커브드 화면

## 벽을 따라 이어지다 ㄱ자로 꺾이는 화면

성수동 레이어41 스튜디오에 마련된 샤넬 코스메틱 팝업스토어에 **P2 LED 전광판**을 시공했습니다.

화면은 벽면 중간에 가로로 길게 들어가고, 벽이 꺾이는 모서리에서 **ㄱ자**로 이어집니다. 화보 영상이 한쪽 벽에서 다른 쪽 벽으로 넘어가는 구성입니다.

## 1. 모서리에서 화면이 끊기지 않아야 합니다

평면 LED를 그대로 맞대면 모서리에 이음선과 각진 틈이 생깁니다. 이번 현장에는 **45도 각도로 가공된 제품**을 사용해 두 면이 모서리에서 맞물리도록 구성했습니다.

- 모서리 맞물림부의 **이음선과 단차 확인**
- 벽 마감선과 화면 상하단의 **정렬 확인**
- 점등 상태에서 모서리를 넘어가는 **영상 연속성 확인**

**평면보다 모서리에서 시공 품질이 드러납니다.**

## 2. 가까이서 보는 화보 영상에 맞춘 P2 피치

팝업스토어 안에서는 관람객이 화면 가까이에서 영상을 보게 됩니다. 얼굴과 피부 톤이 중심이 되는 뷰티 화보는 디테일이 중요하기 때문에 픽셀이 촘촘한 **P2 픽셀피치**를 적용했습니다.

## 3. 인테리어 공정과 함께 진행되는 설치

팝업스토어는 인테리어 마감과 설치가 같은 공간에서 이어집니다. 마감이 진행 중인 공간에서 **화면 설치, 영상 송출 장비 연결, 점등 확인**을 순서대로 진행했습니다.

솔미디어랩은 LED 설치, 렌탈, 유지보수까지 직접 진행합니다. 벽이 꺾이는 구간에 LED가 필요한 팝업스토어, 백화점·쇼핑몰, 쇼룸 현장이라면 계획 단계부터 상담해 주세요.
