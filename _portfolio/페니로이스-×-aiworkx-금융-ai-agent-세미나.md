## 세미나실 한 면을 채운 P1.5 실내 LED 렌탈

서울 종로 서머셋팰리스서울 2층 세미나실에서 열린 **페니로이스 × AIWORKX 금융 AI Agent 세미나**에 **P1.5 실내용 LED** 렌탈 설치 사례 입니다.

호텔 세미나실은 좌석과 화면 사이가 가깝고, 조명을 켠 채로 진행되는 경우가 많습니다. 이 조건에서 발표 화면이 어떻게 읽히는지가 이번 현장의 핵심이었습니다.

## 1. 요구사항: 작은 글씨까지 읽혀야 하는 세미나 화면

이번 세미나 화면에는 행사 타이틀과 부제, 공동 주최 기관 정보, 자막이 들어간 콘텐츠 이미지가 차례로 올라갔습니다. 큰 제목 뿐 아니라 하단의 작은 안내 문구까지 좌석에서 읽혀야 하는 구성입니다.

- 가까운 좌석 거리에서도 글자 윤곽이 무너지지 않을 것
- 형광등과 창가 빛이 있는 공간에서도 화면이 또렷할 것
- 호텔 시설에 별도 시공 없이 세팅하고 행사 후 철수할 수 있을 것

## 2. 왜 P1.5였나

**P1.5는 픽셀 간격이 1.5mm인 미세 피치 LED**입니다. 픽셀이 촘촘한 만큼 가까운 거리에서 보아도 글자와 얇은 선이 뭉개지지 않아, 좌석과 화면이 가까운 세미나실에 잘 맞는 규격입니다.

LED는 화면 자체가 빛을 내는 방식이라, 조명을 끄지 않은 세미나실에서도 발표 자료가 선명하게 보입니다. 이번 현장에서도 실내 조명을 켠 상태로 타이틀 화면과 콘텐츠 이미지를 확인했습니다.

## 3. 아시바 구조물로 세운 자립형 설치

LED 캐비닛을 층층이 쌓아 올리고, 화면 뒤쪽을 **아시바(비계) 구조물**로 받쳐 세웠습니다. 벽면에 화면을 시공하지 않는 자립형 구조라 호텔 공간에 부담을 주지 않고, 행사가 끝나면 철수하기도 수월합니다.

## 4. 점등부터 콘텐츠 송출까지

세팅이 끝나면 전원을 넣기 전후로 화면 상태를 나눠 점검합니다. 모듈 간 이음새와 색 차이, 꺼진 픽셀이 없는지 확인한 뒤 풍경 영상으로 밝기와 색감을 보고, 행사 타이틀 화면과 콘텐츠 이미지를 차례로 송출해 실제 발표 환경에서 가독성을 확인했습니다.

## 세미나실에 맞는 화면을 제안합니다
